# 🎨 VacancyBot — Telegram-бот с красивым Web App

Современный бот для рекрутинга вахтовых рабочих с **анимированным интерфейсом**, **градиентами** и **полноценным веб-приложением**.

## ✨ Возможности

### Для соискателей:
- 🎨 **Красивое Web App** с анимациями и градиентами
- 📝 Заполнение анкеты (Имя, Возраст, Гражданство)
- 💼 Просмотр вакансий с навигацией
- 📍 Локации работы
- 📞 Контакты с кликабельными кнопками
- ❓ Информация о процессе трудоустройства

### Для администраторов:
- 🔧 Админ-панель
- 📋 Просмотр всех анкет
- 📢 Рассылка сообщений
- 📊 Статистика по кандидатам

## 🚀 Быстрый запуск

### Вариант 1: Через start.bat (рекомендуется)
```bash
cd C:\Users\hp\telegram-vacancy-bot
start.bat
```

### Вариант 2: Вручную
```bash
# Терминал 1 - Сервер Web App
cd C:\Users\hp\telegram-vacancy-bot
python server.py

# Терминал 2 - Telegram бот
cd C:\Users\hp\telegram-vacancy-bot
python bot.py
```

## 📁 Структура

```
telegram-vacancy-bot/
├── bot.py              # Telegram бот

├── requirements.txt    # Зависимости
```

## ⚙️ Настройка

1. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

2. **Создайте `.env` файл:**
```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
```

3. **Запустите:**
```bash
start.bat
```

## 🎨 Web App

Web App открывается прямо в Telegram и включает:

- ✨ Градиентные кнопки с анимацией
- 🎬 Плавные переходы и эффекты
- 📱 Адаптивный дизайн
- 🌙 Тёмная тема в стиле "космос"
- 📊 Статистика в реальном времени
- 🔄 Навигация по вакансиям

### Страницы Web App:
1. **Главная** — меню и статистика
2. **Анкета** — форма для соискателей
3. **Вакансии** — список с навигацией ←/→
4. **Локации** — города и объекты
5. **Контакты** — кликабельные кнопки
6. **Помощь** — как это работает

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню с Web App |
| `/admin` | Админ-панель |
| `/cancel` | Отменить действие |

## 🔧 Для продакшена

Для работы Web App в Telegram нужен HTTPS:

1. **ngrok (локально):**
```bash
ngrok http 5000
```
Скопируйте HTTPS URL и вставьте в `bot.py`:
```python
WebAppInfo(url="https://your-domain.ngrok.io")
```

2. **Хостинг:**
- Загрузите `server.py` на PythonAnywhere, Heroku, Railway
- Получите HTTPS URL
- Обновите `bot.py`

3. **Настройка в BotFather:**
- `/mybots` → ваш бот → Bot Settings → Menu Button
- Укажите HTTPS URL Web App

## 📊 API Endpoints

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/` | GET | Web App интерфейс |
| `/api/stats` | GET | Статистика (кандидаты, вакансии) |
| `/api/vacancies` | GET | Список вакансий |
| `/api/submit` | POST | Отправка анкеты |
